# TypeGrid 1.0.6

Write Without Friction. Autosaved On Every Keystroke.

Source release of TypeGrid, an offline note-taking app by Yeasin Arafat Sadiq.

Download and extract **TypeGrid-1.0.6-Source.zip** to inspect the complete source, including the shared interface, desktop wrapper, and build helpers.

This release contains source code only. Packaged Windows, Android, macOS, and Linux installers are not included.

## Development

Inside the extracted source folder:

```sh
npm install
npm run dev
```

The website requires your own environment configuration. The shared app interface is under `public/typegrid/`.
